# UseYourBrain

## Overview

**UseYourBrain** is a Java-based command-line application designed to encourage users to think independently before relying on generative AI.

The application provides structured activities for decision-making, research, brainstorming, and reflection. It helps users organize their thoughts, evaluate information, and review their reasoning before seeking external assistance.

## Features

- **Decision Mode** – Helps users analyze a decision by considering their initial belief, reasoning, benefits, drawbacks, alternatives, evidence, and final decision.
- **Research Mode** – Helps users examine a research question, record sources, compare supporting and challenging evidence, and form a conclusion.
- **Brainstorm Mode** – Helps users generate ideas, identify constraints, evaluate feasible ideas, and choose a direction.
- **Reflection & History** – Allows users to review their current and previously saved sessions.
- **Persistent Storage** – Saves completed sessions locally for access after restarting the application.
- **Input Validation** – Handles empty input and invalid menu or response values.
